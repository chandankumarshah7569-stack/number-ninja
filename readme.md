# MathMaster Pro - Smart Learning Platform

A gamified math learning platform with multiple game modes, achievements, and progression system.

## Features

- **Classic Mode**: Solve math problems with increasing difficulty
- **Practice Mode**: Focus on specific operations (+, -, ×, ÷)
- **Hardcore Mode**: Fast-paced challenge for experts
- **Shooting Mode**: Destroy enemies by solving math problems
- **Battle Mode**: Compete against AI opponents
- **Story Mode**: Travel across India conquering cities

### Gamification
- 🏆 Achievement badges with coin rewards
- 💰 Coin economy and shop system
- ⚡ Power-ups (Time Freeze, Double Points, Shield, Hint)
- 🎨 8 unlockable themes
- 👤 12 selectable avatars
- ✨ 6 animated backgrounds (all free!)
- 📊 Performance analytics
- 🔥 Daily streak system

## How to Play

1. Open `index.html` in your browser
2. Choose a game mode
3. Solve math problems to earn points and coins
4. Unlock themes, avatars, and backgrounds in the shop
5. Track your progress in analytics

## Technologies Used

- HTML5
- CSS3 (with animations)
- Vanilla JavaScript
- LocalStorage for data persistence

## Installation

1. Clone or download this repository
2. Open `index.html` in any modern web browser
3. Start playing!

## Files Structure

- `index.html` - Main HTML file
- `style.css` - Main styles and animations
- `script.js` - Core game logic
- `features-addon.js` - Shop, settings, and gamification features
- `battle-mode.js` - 1v1 battle mode
- `story-mode.js` - India journey story mode
- `story-mode.css` - Story mode styles
- `emoji-patch.js` - Emoji encoding fix
